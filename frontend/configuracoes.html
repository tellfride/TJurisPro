Notificações via Telegram

Crie um bot com o @BotFather no Telegram, copie o token gerado e o ID do grupo/chat para onde deseja receber os avisos de novos clientes, novos empréstimos e vencimentos próximos.

Modelos de mensagem WhatsApp

Cadastre modelos prontos pra usar ao mandar cobrança/lembrete via WhatsApp. Use {{cliente}}, {{valor}}, {{vencimento}}, {{parcela}} e {{emprestimo}} — são preenchidos automaticamente na hora de enviar. Na hora de cobrar (botão 💬 Cobrar via WhatsApp), escolha o modelo no seletor e ajuste o texto antes de abrir o WhatsApp. O botão Adicionar modelos padrão traz de volta os modelos prontos que você apagar. Obs.: {{parcela}} só é preenchido ao cobrar pela página do empréstimo (não pelo 💬 do dashboard).
